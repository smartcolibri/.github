# smartcolibri/.github

Organization profile for [github.com/smartcolibri](https://github.com/smartcolibri).

- `profile/README.md` is the page shown on the organization overview.
- `profile/assets/` holds the light/dark banners and the avatar, generated by `scripts/make_banners.py`.

Regenerate the assets (text is converted to outlines, so no web font is needed at render time):

```sh
python3 -m venv .venv && .venv/bin/pip install fonttools brotli
mkdir -p /tmp/fonts && for f in fraunces fraunces-italic inter; do
  curl -sfL https://smartcolibri.github.io/assets/fonts/$f-var.woff2 -o /tmp/fonts/$f.woff2; done
curl -sfL https://smartcolibri.github.io/assets/fonts/plex-mono-500.woff2 -o /tmp/fonts/plexmono500.woff2
.venv/bin/python scripts/make_banners.py /tmp/fonts
```
