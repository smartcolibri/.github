# smartcolibri/.github

Organization profile for [github.com/smartcolibri](https://github.com/smartcolibri).

- `profile/README.md` is the page shown on the organization overview.
- `profile/assets/` holds the banner (white paper, shown in every theme), one image per app row and the avatar, generated by `scripts/make_banners.py` from the www.smartcolibri.fr design tokens (navy, white, Source Serif 4, Inter).

Regenerate the assets (text is converted to outlines, so no web font is needed at render time):

```sh
python3 -m venv .venv && .venv/bin/pip install fonttools brotli
mkdir -p /tmp/fonts && B=https://www.smartcolibri.fr/assets/fonts
curl -sfL $B/source-serif-4-latin-opsz-normal.woff2 -o /tmp/fonts/sourceserif-normal.woff2
curl -sfL $B/source-serif-4-latin-wght-italic.woff2 -o /tmp/fonts/sourceserif-italic.woff2
curl -sfL $B/inter-var.woff2 -o /tmp/fonts/inter.woff2
.venv/bin/python scripts/make_banners.py /tmp/fonts /tmp/icons
```

`/tmp/icons` holds the 112 px app icons as PNG (`smartcolibri.github.io/assets/apps/*.webp`, converted with `sips -s format png`).
